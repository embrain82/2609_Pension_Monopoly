## 실제 브라우저 조작

Ego Browser TaskSpace 19에서 로컬 개발 서버를 사용했습니다. 게임 저장을 주입하거나 엔진을 직접 호출해서 턴을 건너뛰지 않았습니다. 포커스 후 Enter로 실제 버튼을 조작했습니다.

1. 새 판, 안정형 진단, 원리금보장형 사전지정, 주사위.
2. 첫 턴 추가납입 100만원: 생활 지갑→대기자금 미리보기, 추가납입 맥락의 매수·매도 화살표 0개, 보유상품 불변 설명 확인.
3. 정산 핵심 3금액, 펼침 안의 예금·단기채 손익 이유, 개념 예시 확인.
4. 납입한도 퀴즈 정답: 학습 4→6점, 퀴즈 1개 정답, 최종 종합점수 기여 +2. 정답 전후 생활자금·IRP 대기자금·보유상품·주문·계좌·낙폭·위반 필드 불변. [비교](quiz-financial-invariance.json)
5. 생활사건 해결, 유지 운용, 선택 퀴즈 건너뛰기 확인을 거쳐 **12턴 완주**. 예금 만기와 디폴트옵션 대기·통지 흐름 유지.
6. 연금(20년) 선택·확정 후 결과: 종합84/100 = 연금목표50 + 안정성28 + 학습6. 퀴즈 기여+2 표시. 목표용 월 환산액514,237원 / 목표500,000원. [결과 DOM](final.json) · [점수 표시 검사](final-score-check.json). 완주하면 진행 중 저장이 지워지는 기존 동작으로 final.json의 save는 null입니다.

증거: [1턴](turn1.json), [퀴즈 정답](quiz-answer.json), [반복 진행 버튼 기록](play-actions.jsonl). turn1의 일부 문구는 마지막 안내 접기 개선 전 HMR 시점이며 금액 비교 기준은 동일합니다.
