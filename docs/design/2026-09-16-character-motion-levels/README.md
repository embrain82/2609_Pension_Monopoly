# 캐릭터 애니메이션 강도 1~5단계 비교

2026-09-16 · 사용자 요청: 이전 표정 샘플을 1단계로, 5단계를 아주 강하게 설정해 직접 비교할 수 있는 샘플 제작.

## 화면 구성

- 올리·원이·단지·달리·코리 5종과 평온·긴장·기쁨 3표정.
- 선택 강도 확대 화면, 슬라이더 및 1~5 버튼.
- 같은 캐릭터/표정의 다섯 강도를 동시에 재생하는 비교 카드. 모바일에서는 가로 스크롤.
- 개별 재생, 반복 재생, 모두 정지, 움직임 줄이기.
- 표정별 강도를 별도로 선택하고 검토 의견을 복사. 새로고침하면 1단계로 초기화.
- PNG 5개 base64 내장. 외부 폰트·이미지·스크립트 요청 없음. 게임 코드나 플레이 저장소를 참조하지 않는 독립 HTML.

## 강도 정의

| 단계 | 평온 세로 확대 | 긴장 좌우 이동 | 기쁨 점프 높이 |
|---|---:|---:|---:|
| 1 · 현재 | +2.5% | ±0.8 | 2.5 |
| 2 · 조금 또렷하게 | +5% | ±2 | 6 |
| 3 · 확실하게 | +8.5% | ±4 | 12 |
| 4 · 강하게 | +13% | ±7 | 20 |
| 5 · 아주 강하게 | +20% | ±11 | 30 |

이동량은 한 칸 100×100 좌표 기준. 평온 1.6초 / 긴장 0.7초 / 기쁨 1초로 고정해 강도만 비교한다. 2~5단계는 기울기, 기쁨 착지 탄성도 점차 증가한다. 1단계 키프레임·재생 시간·ease-in-out 곡선은 이전 샘플 그대로다. 비교할 때 시작 시점을 같은 document timeline으로 맞춘다.

선택을 바꾸거나 모두 정지를 누르면 기존 Animation을 취소한다. 시스템/페이지 움직임 줄이기와 문서 숨김에서도 취소한다. 재생이 끝난 뒤 transform은 정지 자세로 복귀한다.

## 생성과 검증

`node docs/design/2026-09-16-character-motion-levels/build.mjs`

- ego-browser: 5캐릭터×3표정×5강도 = 75 조합, 애니메이션당 21시점 = 1,575시점 검사.
- 캐릭터가 실제 표시되는 SVG viewport의 네 모서리를 화면 좌표로 변환해 이름·미리보기 경계를 검사했다. 원본 sprite 전체 이미지의 잘리지 않은 경계는 가독성 검사에 사용하지 않는다.
- 1단계 키프레임 이전 샘플과 일치. 이름 침범/미리보기 경계 초과 없음.
- 표정별 선택 기억, 반복 5개, 정지/동작 줄이기 0개 애니메이션 확인.
- 320/390/768/1440px에서 페이지 가로 넘침 없음. 모바일 비교 카드 영역에만 가로 스크롤.
- JS 구문 검사 및 5개 base64 이미지 디코딩 확인. 자세한 결과: `qa-results.json`.
- 샘플만 제작했으며 운영 게임 코드는 변경하지 않았다.
