# Ego Browser 플레이 리뷰 · 2026-09-12

[HTML 검토서와 상세 구현 계획](review-and-implementation-plan.html) · [20개 후보 데이터](review-items.json) · [승인 상태 관리](../../backlog/review-candidates-2026-09-12.md)

사용자 요청에 따라 기능·과정·설명 10개와 시각 디자인 10개의 개선 후보를 도출한 **검토·계획 산출물**입니다. 20개 모두 미승인 상태이며 게임 실행 코드와 배포본에는 적용하지 않았습니다. HTML 체크박스는 검토 메모일 뿐 승인 기록이 아닙니다.

## 확인 범위

- 기준: v1.6.0 / `28579c6bdcb8837f89655e3732bd838f9fc8214d`.
- 운영 JavaScript와 로컬 미리보기의 파일명·SHA-256이 동일한 것을 확인했습니다. 상세 값은 [환경 기록](review-metadata.json)에 있습니다.
- Ego Browser TaskSpace 17에서 두 판을 각 12턴씩 실제 UI로 완주했습니다. 별도 로컬 주소를 사용해 운영 주소의 기존 저장을 보존했습니다.
- A: 금리의 두 얼굴 / 연금 목표 / 위험중립형. 옵션 매수·부분 환매, 일반 매수·매도·교체·리밸런싱, 추가납입, 행동 2회, X 취소 후 재진입, 포트폴리오, 퀴즈, 연금 수령.
- B: 물가와의 경주 / 든든한 생활 / 위험중립형. 사전지정 안 함, 9턴에 걸쳐 200만원씩 납입, 납입 한도 소진, 생활사건, 퀴즈 건너뛰기, 일시금 수령.
- C는 현재 엔진·렌더러에 생활자금 100만원/이사비 250만원을 입력한 **별도 경계조건**입니다. 두 UI 완주 중 발생한 상황으로 세지 않습니다. [재현 스크립트](audit-evidence.ts) / [결과](boundary-evidence.json) / [화면](boundary-fixture.html).
- 모바일 390×844, 데스크톱 1440×1000 중심으로 화면을 확인했습니다. 실제 iOS Safari와 실기기 터치·오디오 청감, 모든 성향/시드 조합의 균형은 확인 범위 밖입니다.
- 학습 카드 25개의 질문·정답·해설을 읽고 주요 제도·개념을 공식 자료와 대조했습니다. 상세 링크·확인 시점·추가 검수 범위는 HTML의 제도 점검과 공식 근거에 기록했습니다.
- 기존 `npm test`: 44개 테스트 파일, 483개 테스트 통과. [실행 로그](review-tests.log). 이는 현재 코드의 회귀 검증이며 개선 후보의 구현 완료를 의미하지 않습니다.

## 근거 파일 읽는 법

- `review-run-a.json`, `review-run-b.json`: 게임의 복기 내보내기로 얻은 12턴 기록. 완전한 재개용 저장 파일은 아닙니다.
- `review-a-result.txt`, `review-b-result.txt`, `review-b-mission.txt`: 결과/미션 화면의 읽기 기록.
- `ego-review-events.jsonl`: 플레이 중 수집한 UI 진행 기록. 일부 동선의 연속 기록이며 모든 클릭을 포함한 완전한 녹화는 아닙니다.
- `evidence/`: 실제 플레이 캡처와 첫 턴 관찰. `review-c01-shortage-fixture.png`만 통제 경계조건 캡처입니다.
- `report-data.py`: 문제·제안·복잡도 제한·구현 단계·완료 조건·관련 코드·저장 영향·근거를 가진 20개 계획 원본.
- `build-report.py`: HTML과 JSON 목록 생성기. 게임 코드나 사용자 저장을 수정하지 않습니다.

## 보고서 자체 검증

[보고서 검증 기록](report-validation.json): 20개 항목, 기능/디자인/P0 필터, 선택/해제, 상세 펼침, 링크 이동, 미션·납입 예시를 Ego Browser에서 확인했습니다. 390px와 1440px의 DOM 치수상 가로 넘침이 없고 로컬 링크 289개에 누락이 없었습니다. 보고서의 추가 스크린샷 캡처는 시간 초과로 저장하지 못했습니다. 앞서 수집한 실제 게임 화면 근거와 구분하며, 보고서의 이미지 기반 최종 시각 검수까지 완료했다고 주장하지 않습니다.

## 계획 갱신

원본 항목을 수정한 후 저장소 루트에서 실행합니다.

```sh
python3 docs/reviews/2026-09-12-playthrough/build-report.py
```

후속 구현은 사용자가 지정한 번호만 진행합니다. F01~F04를 우선 검토하고, 계산·설명 기준 → 거래 흐름 → 플레이 박자 → 보드/캐릭터/결과 표현 순서로 나눠 검증하는 안입니다. 연계 후보도 자동 승인되지 않습니다. 기존 FB-001~006의 완료 상태와 별도 디폴트옵션 자동운용 백로그를 유지합니다.
