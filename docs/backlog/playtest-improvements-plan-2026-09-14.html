  1. 확인창 X·Esc: 원래 정산 또는 퀴즈 화면으로 돌아갑니다. 스크롤과 선택 문맥을 복원하고 점수·진행을 변경하지 않습니다.
  2. 퀴즈 풀기: 원래 큐에서 실제 응답 가능한 첫 문제를 엽니다. 별도 문제를 만들거나 중복 채점하지 않습니다.
  3. 그냥 넘어가기: 요청했던 이동만 실행합니다. 정산을 떠나는 것은 모든 퀴즈를 영구 포기하는 동작으로 바꾸지 않습니다. 퀴즈 창에서 한 문제를 명시적으로 건너뛰는 기존 의미는 유지합니다.
  4. 반복 억제: 같은 턴에서 넘어가기를 확인한 문제 ID를 기록합니다. 남은 문제가 모두 확인한 ID에 포함되면 다음 주사위에서 다시 묻지 않습니다. 새 문제가 생겼거나 다음 턴이면 다시 판정합니다.
  5. 점수 문구: 「풀면 무조건 +2」나 「넘기면 −2」라고 하지 않습니다. 현재 규칙에서 실제 추가 가능한 최대 점수만 안내합니다.

현재 beginDiceRoll()은 주사위 연출을 시작하고 moveRolledDice()가 말을 이동시킵니다. 게임판으로 스크롤하는 단계는 없습니다. 화면 이동 → 주사위 결과 → 말 이동 → 도착·시장 반영 순서로 연결합니다.

보여주는 방식

  • 말의 경로가 있는 게임판 영역을 기준으로 화면 안에 있는지 판단합니다.
  • 이미 잘 보이면 스크롤하지 않습니다. 화면 밖이면 약 250~350ms 안에 부드럽게 이동합니다.
  • 모바일 주소창, 하단 고정 운용 바, 안전 영역을 제외한 실제 가시 영역을 사용합니다.
  • 한 칸 이동할 때마다 화면을 따라 움직이지 않습니다. 작은 가로 화면에서 판 전체가 들어가지 않으면 출발·도착 영역이 최대한 보이도록 배치합니다.

중단·접근성

  • 동작 줄이기 설정이면 즉시 위치를 맞추고 기존 즉시 이동 모드를 따릅니다.
  • 키보드 포커스는 게임판의 안정적인 요소로 한 번만 이동하며 추가 스크롤을 일으키지 않습니다.
  • 사용자가 스크롤에 개입하면 자동 이동을 중단해 화면을 끌어당기지 않습니다.
  • 앱이 가려지거나 새 게임으로 전환되면 대기·연출을 취소합니다. 다음 재개에서 같은 턴을 정상 시작합니다.
