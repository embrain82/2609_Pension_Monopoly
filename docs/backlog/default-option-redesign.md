# 디폴트옵션 거래 메뉴 재설계

상태: 보류 · 단계 B에서 제외 · 2026-09-10 사용자 요청

문제: 운용하기의 옵트인·옵트아웃·현재 현금 유지 선택지가 첫 화면을 복잡하게 만듭니다. v1.2.1에서는 추가 UI 및 관련 자동운용 구현을 단계 A로 복원했습니다.

## 다음 검토안 (미구현)

1. 운용지시 메뉴에는 「디폴트옵션 옵트인/아웃」 진입점 하나만 표시합니다.
2. 별도 창에서 옵트인(운용 시작)과 옵트아웃(운용 종료)을 설명과 함께 구분합니다.
3. 현재 지정 상품·대상 금액·미결제 주문을 보여 주고 선택 결과를 미리 확인합니다.
4. 취소하면 자산과 행동 횟수는 바뀌지 않고 운용 메뉴로 돌아갑니다.

## 구현 전 결정할 사항

- 기존 「이번엔 그대로」와 지정옵션 실행의 관계 및 중복 진입 제거.
- 현금 유지 선택의 필요성과 적절한 위치.
- 지정·변경·해제, 옵트인·옵트아웃의 개념과 실제 제도 절차를 공식 자료로 재검토.
- 만기/납입 자금 구분, 통지·대기 시간의 게임 내 표현, 거래 한도와 결제 처리.
- 플레이어가 첫 화면 설명만으로 선택 결과를 이해할 수 있는지 사용성 검증.

## 구현 순서와 완료 조건

화면 흐름 시안 → 규칙 확정 → 엔진/화면 구현 → 회계·행동 횟수·취소·중복 주문 회귀 검증 → 매뉴얼 갱신 → 플레이 테스트.
첫 운용 화면의 디폴트옵션 관련 진입점은 하나여야 하고, 별도 창에서 실행 전 결과를 이해할 수 있어야 합니다. 이 항목은 현재 B 완료 조건에 포함하지 않습니다.
