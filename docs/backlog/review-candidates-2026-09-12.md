## 추천 순서

1. P0 판단 기준: F01 → F02 → F03 → F04. v1.6.1 완료.
2. P1 시작 조건과 설명: F06 → FB-007.
3. P1 공통 표시: D05·D06.
4. P1 거래·보유 확인: F05 → F07 → D07·D09.
5. P1 화면 배치·게임판: D04 → D02.
6. P1 플레이·마무리: F08 → F10.
7. P2 별도 후속: D03 → F09 → D08 → D10 → D01.

신규 FB-007은 [사용자 피드백 원장](playtest-improvements.md)에 원 요청을 기록합니다. 원본 HTML은 최초 20개 리뷰 계획을 보존하고 최신 P1 목록을 연결합니다. 이후 사용자 “P1 스텝 구현해보자” 요청으로 12개 전체 구현을 승인했습니다.

일부만 컨펌한 경우에는 상세 계획에 기재한 대체 범위를 적용합니다. 예를 들어 D10만 승인하면 미승인 F09의 자동 도장 규칙은 적용하지 않습니다. 신규 규칙은 기존 판·최고 기록과 구분하는 호환 계획을 먼저 따릅니다.

기존 FB-001~006은 구현·검증 완료 상태로 유지합니다. X 취소, 하단 포트폴리오, 시장 상세 강조, 턴당 합계 200만원 제한을 되돌리지 않습니다. 매턴 경로 토큰 선택과 실제 디폴트옵션 자동운용은 이번 후보에 포함하지 않습니다.

## 승인 이력

- 2026-09-12 · 사용자 “P0 4개 과제 진행하자”로 F01~F04 승인. 검토서의 해당 4개 범위만 구현합니다. F05~F10과 D01~D10은 미승인 상태를 유지합니다. 세금·점수·시장 경로 및 기존 거래 규칙은 보존합니다.

- 2026-09-12 · F01~F04를 순차 구현하고 521개 테스트·80개 시장 경로 동일성·Ego Browser 2회 완주·저장 복원 검증 완료. [구현 기록](../implementation/2026-09-12-review-p0.md). 나머지 16개는 컨펌 대기 유지.

- 2026-09-12 · 사용자 요청으로 FB-007(시작 전 성향 확인·옵션 선택·최종 시작)을 P1에 추가하고 12개 P1 목록 작성. 원본 리뷰 번호·승인 상태와 별도 디폴트옵션 후속 검토 상태는 유지. 애플리케이션 변경 없음.

- 2026-09-12 · 사용자 “P1 스텝 구현해보자”로 FB-007과 기존 P1 11개 전체 승인·구현. P2 5개와 별도 디폴트옵션 후속 검토는 보류. [v1.7.0 검증 기록](../implementation/2026-09-12-review-p1.md).
