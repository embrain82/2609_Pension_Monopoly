## FB-007 상세 범위

사용자 요청: “게임 시작후 성향 변경을 막을거면 게임 시작전에 투자자성향을 먼저 알려주고, 그에 맞는 디폴트를 선택하도록 하고 게임을 시작하는게 맞을거 같아.”

기본 흐름은 **성향 확인·필요 시 진단 → 결과와 의미 확인 → 해당 성향에 맞는 디폴트옵션 선택 → 시작 조건 확인·게임 시작**으로 정리합니다.

성향 확인과 옵션 선택의 두 준비 단계 안에 결과 설명·최종 확인을 배치해, 확인할 때마다 별도 팝업이 늘어나지 않도록 F08과 함께 설계합니다.

- **성향 먼저 확인:** 저장된 성향이 있으면 이름과 의미를 보여주고 유지 또는 다시 진단할 수 있게 합니다. 실제 진단 여부가 불명확한 기본 성향을 진단 결과로 표현하지 않으며, 진단 이력과 기존 저장의 처리 기준을 상세 계획에서 정합니다. 매번 긴 진단을 강제로 반복하는 흐름은 피합니다.
- **선택에 필요한 설명:** 성향에 따른 게임 내 매수 가능 범위와 시작 구성을 짧게 보여줍니다. 성향은 캐릭터 외형과 다르며, 게임 시작 후 고정된다는 안내를 확정 전에 제공합니다.
- **성향에 맞는 옵션:** 확인한 성향을 추천의 기준으로 사용하고, 기존의 「성향 추천」과 「현재 선택됨」 표식을 유지합니다. 뒤로 돌아가 성향을 바꾸면 선택 상품의 적합 여부를 다시 확인하고, 필요한 재선택을 명확히 안내합니다.
- **지정과 매수 구분:** 여기서 선택하는 것은 사전지정입니다. 지정만으로 매수되지 않는 현재 규칙을 유지하며 실제 거래는 게임 내 옵트인으로 진행합니다. 자동운용을 추가하지 않습니다.
- **시작 시점:** 준비가 끝나 최종 시작을 누를 때 게임 상태를 생성·확정합니다. 준비 중 닫기·뒤로 가기로 진행 중 저장을 덮어쓰거나 게임을 시작하지 않도록 합니다.
- **시작 후 안내:** 현재 판에서 성향을 변경할 수 없다는 사유를 해당 버튼 가까이에 표시합니다. 설정의 “지금 판부터 바로 바뀝니다”와 성향 점검 칸의 재진단 권유 등 모순된 안내를 함께 정리합니다.
- **반복 플레이·호환:** 이어하기는 현재 판의 성향·자산·주문을 보존합니다. 새 판과 같은 시드 재도전은 시작 조건을 확인할 수 있도록 연결하고, 주간 도전의 고정 조건은 시작 전에 명시합니다.

연계: F06의 공통 용어·설명, F08의 짧은 시작 안내, F10의 재도전 진입, D06·D07의 선택 표시·화면 구성. **등록 ID는 FB-007 하나로 유지하고 F08과 중복 집계하지 않습니다.**

완료 판단: 최초 사용자·저장 성향 사용자·기존 진행 이어하기·재도전·주간 도전에서 시작 조건이 명확하고, 성향 변경 시 옵션 추천·선택이 함께 검토되며, 시작 전 취소로 자산이나 저장이 바뀌지 않아야 합니다.

## 순차 진행 제안

1. **시작 조건과 설명:** F06 → FB-007. 성향·옵션을 알고 시작하는 흐름과 안내를 우선 정리.
2. **공통 표시:** D05·D06. 이후 화면에서 사용할 글자·금액·상태 표현 정리.
3. **거래와 보유 확인:** F05 → F07 → D07·D09. 미리보기·결제·만기·포트폴리오 연결.
4. **화면 배치와 게임판:** D04 → D02. 핵심 정보 배치와 칸·지역 식별 개선.
5. **플레이와 마무리:** F08 → F10. 반복 안내를 줄이고 12턴 완주·재도전까지 검증.

각 묶음은 관련 검증 후 다음 묶음으로 진행합니다. 세부 설계·의존관계는 구현 착수 시 현재 코드와 대조합니다.
