02 · FB-017

“개념 이름”에서 “이럴 때 무엇을 알아야 할까”로

현재는 25개 학습 카드의 정답·오답이 지나치게 짧거나 대비가 커서, 문제를 맞혀도 실제 금융 판단으로 연결되기 어렵습니다. 금융·퇴직연금 주제는 유지하면서 생활 속 상식과 오해를 다룹니다.

문항 작성 규칙

  • 질문은 1~2문장, 조건은 분명하게. 금액·세율 암기보다 원리와 판단을 우선합니다.
  • 보기는 같은 문장 형태와 비슷한 길이의 3개. “둘 다 없다” 같은 명백한 허수 보기를 줄입니다.
  • 정답이 하나로 정해지지 않는 투자 추천은 피합니다. 조건을 명시하고 사실을 묻습니다.
  • 해설은 2~3문장: 정답 이유 → 흔한 오해 → 게임에 연결되는 한 줄.
  • 세법·인출 요건·규제 예외는 최신 공식 출처와 확인일을 관리합니다.

게임의 부담은 유지합니다

  • 한 번에 한 문제, 보기 3개, 정답 +2점·오답 벌점 없음.
  • 기존 퀴즈 등장 빈도·건너뛰기 확인·중복 출제 방지·점수 상한을 유지합니다.
  • 쉬운 이해 60% / 짧은 적용 40%를 목표로 편집합니다.
  • 법령 숫자와 예외는 ‘더 알아보기’에서 확인합니다.
  • 정답 위치는 문항 전체에서 균등하게 배치하고, 긴 답이 항상 정답인 패턴을 점검합니다.

문항 예시 8개 · 직접 눌러보기

편집 방향을 확인하는 초안입니다. 최종 25문항은 구현 단계에서 문항별 출처·조건·보기 모호성을 다시 검수합니다.

문제 파일만 덮어쓰면, 답을 고른 상태에서 이어하기를 했을 때 문장과 정답 위치가 달라질 수 있습니다. 새 판은 새 문제은행을 사용하고 기존 판은 해당 판의 문제 버전을 유지합니다.

  • 퀴즈 선택용 난수는 기존처럼 시장 난수와 분리합니다. 문항 수정이 주사위·시장 결과를 바꾸면 안 됩니다.

03 · FB-018

만기 자금이 지정 상품으로 이어지는 흐름

현재 코드는 만기까지 약정 이자를 지급한 뒤 예금 보유분에 남겨 두며, 이후 이자를 중단합니다. 현대 거래 규칙에서는 옵트인으로 직접 사는 기능만 있습니다. 이번 안은 만기 처리와 자동운용 상태를 새로 연결합니다.

공식 자료에서 확인한 실제 절차

구분확인한 내용설계에 반영할 점
기존 상품 만기만기 후 4주간 지시가 없으면 통지하고, 통지 후 2주간 지시가 없으면 사전지정운용방법을 적용합니다. [1] [2]단순히 ‘만기 6주 뒤’로 계산하지 않고 실제 통지 단계를 별도로 저장
신규 가입자의 미지시 자금기존 상품 만기와 시작점이 다릅니다. 통지 후 2주 절차를 적용합니다. [1] [3]이번에는 기존 운용 예금의 만기부터 구현. 시작 대기자금·일반 추가납입 전체에 만기 타이머를 붙이지 않음
만기·대기 중 자금현금성 자산으로 대기하는 동안 낮은 금리가 적용될 수 있습니다. 개별 상품·계약 조건을 확인해야 합니다. [2] [3]게임의 기존 대기자금 이자 규칙 사용. 실제 은행 금리라고 표현하지 않음
디폴트옵션 안의 예금확인한 퇴직연금 정기예금 설명서는 펀드 포함 포트폴리오의 예금은 자동 재예치, 펀드 미포함 구성은 만기 자동해지를 구분합니다. [4]모든 예금을 똑같이 현금화하지 않고 구성별 만기 정책 사용. 특정 상품 사례를 모든 은행의 공통 규정으로 일반화하지 않음
직접 운용할 권리대기 중 운용지시와 직접 옵트인이 가능하며, 적용 후에도 다른 운용방법을 선택할 수 있습니다. [1] [2]직접 매수·교체·옵트인·옵트아웃 경로를 유지

핵심 구분: 사전지정은 ‘지금 즉시 매수’와 다릅니다. 일반 매도 대금·추가납입·모든 대기자금이 무조건 만기 예금과 같은 절차로 자동 매수되는 것도 아닙니다. 이번 범위는 추적 가능한 만기 자금입니다.
