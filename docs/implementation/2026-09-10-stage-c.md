# 단계 C · 재미 강화 (v1.3.0)

기준: v1.2.1. 합의한 순서 ④ 렌더링·이동 → ③ 경로·지역 미션 → ⑤ 턴 흐름·복구를 적용했습니다.

## 구현

- 보드·말·입력 DOM은 속성/텍스트 변경으로 유지합니다. 이동 프레임은 보드만 갱신합니다. 말 이동은 Web Animations 완료를 기다리고 취소 세대가 바뀌면 이전 작업이 종료됩니다. 숫자 애니메이션도 이전 갱신이 새 값을 덮어쓰지 않게 처리합니다.
- 두 눈 합 이동은 무료, 큰 눈 하나 이동은 토큰 1개. 시작 2개/상한 4개, 첫 더블 한 번 +1. 경로 확정은 자산을 바꾸지 않으며 startTurn에서 시장·급여·통과 효과를 한 번 처리합니다. 주사위 난수는 기존 스트림을 유지합니다.
- 4개 구역은 6칸씩: 안정/성장/생활/은퇴. 서로 다른 2개 칸 방문 후 검토 이유를 선택하면 지역당 도장·토큰을 한 번 받습니다. 매수 필요 없음, 수익률/법정한도/지식 점수 보상 없음. 도장은 해당 판의 결과에도 표시합니다.
- 칸 터치, 방향키 탐색과 Enter/Space로 정보 카드. 좁은 화면은 14px 이상 정보 카드에서 칸 효과를 읽습니다.
- 일반 턴은 주사위→경로→운용으로 연결하고 시장 요약/상세를 운용 화면에 통합했습니다. 충격·퀴즈·사건은 필요할 때 별도 표시합니다. 일반 턴의 마감까지 필수 클릭은 3회(정산 닫기와 개별 거래 상품/금액 설정 제외)입니다.
- 첫 2턴에 납입/매수 실습 안내. 기본 매수 외에 기존 상품 매도·교체도 가능함을 설명합니다.
- 결정 경계에 전체 게임과 퀴즈·정산 정보를 별도 진행 저장(c1)으로 보관합니다. 진행 중 리로드는 타이틀의 이어서 플레이로 복원합니다. 확정된 경로는 토큰을 다시 소비하지 않고 같은 이동을 재현합니다. 미확정 거래 입력은 복구 시 목록에서 다시 선택합니다.

## 추가 요청 판단

운용 선택 취소·포트폴리오 조회는 기본 탐색 동작이라 ⑤와 함께 구현했습니다. ×/Esc/취소하고 보드로는 거래나 턴 마감 없이 창만 닫습니다. 직접 포트폴리오 확인 후 기존 선택 화면으로 복귀할 수 있습니다. 운용지시 칸의 두 번째 행동에서도 이미 실행한 거래와 남은 행동을 유지합니다. 이미 접수한 주문을 취소하는 기능은 아닙니다.

디폴트옵션의 2단계 거래 메뉴 재설계는 [별도 보류 항목](../backlog/default-option-redesign.md)을 유지합니다.

## 검증과 한계

엔진: 경로 중복 선택·토큰 부족·통과 환급·중복 턴 차단·도장 중복 보상·200판 완주.
UI: 취소/포트폴리오 왕복의 게임 상태 불변, 입력 포커스·보드·말 노드 유지, Esc, 거래 후 복구, 취소 타이머, 12턴 UI 완주 및 결과 집계/진행 저장 제거.
브라우저: 기본 데스크톱과 390×844 모바일 표시, 경로 미리보기/이동, 운용 취소·조회·복귀, 새로고침 이어하기 확인.

지정 중급 모바일의 지연 p95와 실제 FPS, 초보자 완주 시간·선택 이유 설명률 등 사람 대상 목표치는 측정하지 않았습니다. 기존 효과음 수정·성향 분리·P0 회계 검증은 유지합니다. D의 시장 모형·승리 조건·운영 도구 전면 개편은 다음 단계입니다.

최종 검증: 37파일 398개 테스트, 타입 검사·빌드·린트 통과. 1,100판 기존 전략 시뮬레이션과 200판 두 경로 검증에서 오류·미종료 없음. 실제 브라우저 weekly-2026-W37에서 첫 턴 짧은 경로 후 기본 경로로 12턴 완주, 생활사건 해결·퀴즈 건너뛰기·20년 연금 수령까지 확인했습니다. 시장 경로가 같은 고스트도 경로/생활 선택이 달라질 수 있음을 결과 설명에 명시했습니다.
