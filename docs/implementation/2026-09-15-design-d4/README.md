## 적용 내용

| 항목 | 동작과 범위 |
| --- | --- |
| FB-012 미진단 | 성향 이름·눈금·매수 등급·시작 배분 대신 진단 안내와 5문항 버튼을 표시한다. 유효한 진단/확인 이력만 재사용한다. 설정만 저장한 뒤 새로고침해도 진단 결과를 만들어내지 않는다. 진단 → 결과 확인 → 디폴트옵션 → 최종 시작 순서이며 중간 취소는 기존 진행을 보존한다. 주간 도전은 공통 성향임을 구분한다. |
| FB-013 문항 테두리 | 질문 번호·답안별 DOM 키로 버튼을 교체하고 터치에 마우스 hover 강조를 적용하지 않는다. 새 질문으로 초점을 옮기며 키보드 focus-visible을 유지한다. 이전 질문 버튼의 늦은 클릭 이벤트도 거부한다. |

| FB-015 대기 이자 | 신규 판의 턴 시작 주문 가능 IRP 현금 × 0.001을 시장 단계에서 한 번 지급한다. 이번 턴 납입액과 이번 턴 결제 대금은 다음 턴부터 대상이다. 예약 매수·미결제 매도·생활자금·보유 예금은 제외한다. 정산·시장 영향·포트폴리오·운용 메뉴에서 게임 가정과 실제 지급액을 표시한다. |
| D4 보조 화면 | 설정을 화면·캐릭터 / 소리·진행 / 이번 판 조건으로 묶고 A-1 색·서체·버튼·카드를 적용한다. 도움말·타임라인·게임판 둘러보기·도감·목표 화면도 연결한다. 도감의 학습·업적·컬렉션 탭은 패널 연결과 좌우/Home/End 키를 지원한다. |
| 매뉴얼 | 사용자·운영자·공통 학습 문서를 현재 A-1 스타일로 생성한다. 시작 순서·초기 배분·대기 이자·수령 선택 확정·저장 호환성을 반영한다. 과거 버전 매뉴얼은 보존한다. |

턴당 0.1%는 실제 금융회사의 연이율이 아닌 교육용 게임 값이다. 이자는 내부 운용손익에 포함하며 외부 납입·세액공제 대상 원금·입출금으로 계산하지 않는다. 12턴 종료 후 주문 정리를 위해 추가 이자를 만들지 않는다.

## 버전과 저장 호환성

- 금융 규칙 `2026-09-15-f`, 스냅샷 `financeRules.version=f1`, 진행 저장 `c4`. 저장 키와 브라우저 로컬 저장 방식은 유지한다.
- 기존 c1/c2/c3는 원래 배분·대기 이자 0·기존 주문 규칙으로 이어 한다. 기존 판에 신규 자산 규칙을 소급 적용하지 않는다.
- 새 고스트·비교 지수·분기 연습은 해당 판의 초기 배분과 규칙을 사용한다. 구 분기를 새 규칙으로 바꾸지 않는다.
- 저장에는 이자율·초기 배분·마지막 반영 턴·기초 대기자금·실제 이자 금액을 검증한다. 버전 불일치·잘못된 금액·잘못된 분기 스냅샷은 거부한다.
- 재원별 수령 과세와 운용 성과 계산은 기존 엔진을 사용한다. 이자로 납입 원금을 늘리지 않는다.

## 자동 검사

- **62개 파일 / 647개 테스트 통과.** 기존 전체 테스트와 신규 금융 규칙 14개, 시작 경험·보조 화면 검사를 포함한다.
- 타입 검사·린트·프로덕션 빌드 통과.
- 잔액 0·원 미만·큰 금액, 납입 시점, 매수 예약·매도 결제, 같은 턴 재호출, 마지막 정산, 옵트인, 원금 재원, 정산 구성 합계, 고스트·분기·구 저장·손상 저장을 검증했다.
- 기존 UI 테스트 중 확인된 성향을 전제로 하는 항목에 진단 이력 fixture를 명시했다. 미진단 사용자의 별도 테스트를 추가했다.
- [첫 시장·12턴 계산 검사](finance-matrix.json): 실제 신규 엔진으로 공격투자형 네 시장 × 1,000개 시드의 첫 시장을 확인했다. 초과 0/4,000, 최대 위험비중 약 66.15~67.14%. 모든 후속 시장에서 초과하지 않는다는 보장은 아니다.
- 대기·납입 후 현금 유지·ETF 매수·리밸런싱의 네 전략 × 네 시장 × 100개 시드, **1,600판**을 완주하고 잔액·최종 주문·c4 복원을 확인했다. 납입 포함 IRP 총액과 운용지수를 따로 기록했다. 하락장에서 현금 유지가 유리할 수 있으며, 표본을 실제 이용자 승률이나 특정 전략의 보편적 우월성으로 해석하지 않는다.
- 재현: `node --import tsx scripts/verify-finance-rules.mjs`. 이 스크립트는 브라우저 플레이를 대체하지 않는다.

## 직접 브라우저 확인

Ego TaskSpace 6의 로컬 `localhost:5193` 테스트 탭을 사용한다. 운영 사이트의 저장은 변경하지 않는다.

- 모바일 Chromium 390×844·터치 에뮬레이션에서 미진단 안내 → 실제 5문항 클릭 → 공격투자형 결과 → 옵션 → 신규 판을 시작했다. 시작 구성이 35/20/45, 위험비중 65%였다.

- 정상 모드의 첫 주사위에서 두 주사위 굴림 상태와 도착 후 결과 3칸·4번 칸 도착을 확인했다. 굴림·착지 애니메이션을 화면으로 관찰했다는 뜻은 아니다.
- Mac 잠금으로 스크린샷 도구가 시간 초과했으며 네이티브 도구에서도 잠금을 확인했다. 잠금 해제를 요청한 상태다. D3와 D4의 색·여백·주사위·말 이동 육안 확인, 실제 iOS Safari 키보드·터치·오디오 확인은 대기다.
