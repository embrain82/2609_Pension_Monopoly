# 도착 효과·운용 손익 표정 적용

2026-09-17 · 승인안 구현 완료

- 기쁨: 이번 턴 운용수익률 +1% 이상, 실제 도착 환급·행동 2회·이해 점수 보상, 이번 턴 최초 목표 달성.
- 긴장: 해결 전 생활 사건 또는 이번 턴 운용수익률 -1% 이하. 생활 사건 → 손실 → 수익 → 보상/최초 목표 → 평온 순서로 판정한다.
- 현재 보유분과 시장 노출 주문의 실제 손익 및 당기 대기자금 이자를 사용한다. 입출금, 환급, 원금 이동은 운용수익률에서 제외한다. 실제 내역이 없는 구 저장은 수익률을 추정하지 않는다.
- 도착 효과는 최종 칸의 실제 효과만 읽는다. 통과 환급, 환급 0원, 미발생 사건, 점검 실패, 실행 전 리밸런싱 보상은 기쁨으로 처리하지 않는다.
- 목표 충족이 이후 턴의 표정을 고정하지 않는다. 게임판과 은퇴설계 카드가 동일한 판정 함수를 쓴다.
- 최종 칸 공개/시장 적용 뒤 약 1.2초간 표정과 이유를 보여준 다음 기존 안내 흐름을 연다. 2배속에서도 이 노출 시간은 유지한다. 사용자가 버튼을 먼저 누르면 즉시 진행한다.
- 보드 아래 한 줄 이유를 표시하며 말/칸 이름에는 겹치지 않는다. 평온 1단계, 긴장/기쁨 3단계, 동작 후 2초 휴식 반복을 유지한다.
- 도착 대기 표시는 체크포인트의 선택적 UI 필드 `arrivalPending`에만 저장한다. 금융 GameState 및 규칙 버전은 변경하지 않는다. 새로고침은 시장을 다시 처리하지 않고 표시 단계를 이어간다.
- 조회창·탭 숨김 동안 진행을 멈추고 보드 복귀 시 노출 시간을 다시 확보한다. 운용 진입/거래 실행 시 대기 예약을 취소한다. 움직임 줄이기·캐릭터 끄기에서는 추가 연출 대기를 생략한다.

## 검증

- 70개 파일 / 719개 테스트 통과. lint, typecheck, 프로덕션 build 통과.
- 경계·효과 우선순위 15개, 도착/저장/조회/숨김/즉시 진행 UI 6개 테스트를 추가했다. 기존 주사위·칸 공개·12턴 UI 완주·금융 회계 검증도 통과했다.
- Ego Chromium 390px 새 판: 성향 진단 → 옵션 확인 → 주사위 → 수익 +1.2% 기쁨 → 약 1.227초 뒤 운용창. X로 보드 복귀 후 3회 이상 실제 WAAPI 연출 확인.
- 별도 엔진 시드의 실제 주사위 이동: 운용지시 칸 도착 시 기쁨과 ‘운용 기회가 2회예요’, 약 1.220초 노출, 보드 복귀 후 반복 확인.
- 별도 엔진 체크포인트 이어하기: 수익 +2.7% 기쁨 / 손실 -1.7% 긴장 / 평온을 각각 확인. 세 경우 모두 약 1.22초 노출 후 안내, 3회 이상 애니메이션, 엔진 결과와 전체 GameState 일치.
- 320/390/768/1440px에서 가로 넘침 없음. 이유 영역이 게임판 아래이며 뷰포트 안에 위치하는 것을 DOM 치수로 확인했다.
- 캡처 제약: 이번 실행의 Ego Page.captureScreenshot이 시간 초과하여 새 시각 캡처 파일은 생성하지 못했다. 위 브라우저 검증은 실제 DOM, 화면 전환, WAAPI 호출과 저장 데이터 비교에 근거한다. 실제 iPhone Safari 검증은 아니다.
- 원시 결과: trigger-qa.json. 새 게임 직접 조작과 별도 엔진 체크포인트 검증을 구분해 기록했다.
