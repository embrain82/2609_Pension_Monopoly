# 캐릭터 표정 애니메이션 적용

2026-09-17 · 승인: 평온 1단계 / 긴장 3단계 / 기쁨 3단계. 후속 요청으로 보드가 보이는 동안 반복 재생하도록 변경.

## 적용

- 올리·원이·단지·달리·코리 모두 같은 승인 강도 적용. 기존 평온/긴장/기쁨 이미지와 판정 규칙 유지.
- 평온: 1.6초의 작은 호흡(가로 1%, 세로 2.5% 확대).
- 긴장: 0.7초간 칸 너비의 ±4% 좌우 흔들림과 ±2.5° 기울기.
- 기쁨: 1초간 칸 높이의 12%, 7.2% 두 번 점프, ±5° 기울기와 착지 탄성.
- 보드가 보이는 동안 현재 표정의 연출을 반복. 동작 종료 후 2초 쉬었다가 다음 동작 시작. 운용창·포트폴리오를 닫으면 즉시 재개.
- 안내창·탭 숨김·화면 밖·주사위 이동·칸 공개 중에는 재생 및 예약을 취소. 보드 복귀·새로고침 후 이어하기·캐릭터/표정 변경 시 현재 표정으로 반복 재개. 같은 재렌더·스크롤로 타이머나 애니메이션을 중복 생성하지 않음.
- 앱 및 시스템의 움직임 줄이기, 캐릭터 끄기, 이미지 실패 시 정지 상태. 기존 2배속 설정에서는 재생 시간만 절반.
- 이동용 말 변환과 표정용 SVG 그룹을 분리. 금융 엔진, RNG, 저장 형식, 점수, 주사위, 도장, 칸 공개 규칙은 변경하지 않음.
- 그림자 필터를 최상위 SVG에만 적용해 점프가 잘리지 않으면서 원본 스트립의 옆 표정이 노출되지 않게 처리.

## 검증

- 전체 68개 파일 / 698개 테스트 통과. 타입 검사·린트·프로덕션 빌드 통과.
- 연출 수명주기 10개 테스트: 반복 간격, 재생/예약 취소, 안내창/이미지/가시성, 중복 방지, 캐릭터/표정/속도/너비 변경, 이어하기, 움직임 줄이기, 이미지 실패.
- Ego 브라우저 390px 새 게임 → 첫 주사위 → 운용창 X: 같은 턴에서 3회 이상 반복. 포트폴리오 표시 중 4초간 추가 재생 0회, 복귀 시 재개, 최대 동시 애니메이션 1개, 금융 상태 변화 0건.
- 이전 1회 재생 정책은 폐기. 이어하기는 저장된 금융 상태를 그대로 복원하고 표정 연출만 새로 반복한다.
- 실제 게임 렌더러로 5캐릭터 × 3표정 × 4너비(320/390/768/1440px), 각 21시점 검사. 이름 침범 0건, 보수적인 SVG 사각형 기준 최소 간격 2.84px.
- 원본 스트립을 자르는 내부 SVG의 overflow:hidden / filter:none, 바깥 SVG의 overflow:visible 확인. 전체 캐릭터 캡처로 시각 검증.
- 실제 직접 플레이와 별도 시각 검사 fixture를 구분. happy/tense 강도와 이름 간격은 fixture에서 검사.

## 기쁨·긴장 미표시 재점검

- 증상과 조건을 분리해 확인: 기쁨은 목표 월 환산액 달성 시에만, 긴장은 목표 미달 상태에서 시장 충격 또는 5% 이상 하락 시에만 선택됐다. 일반적인 수익·작은 손실은 평온이다. 감정 세 종류를 순서대로 자동 순환하는 기능은 아니다.
- 기존 반복 Preview의 JavaScript를 인증된 브라우저에서 읽어 로컬 검증본과 SHA-256 일치를 확인했다. 애니메이션/이미지 누락이나 이전 배포 파일 문제는 재현되지 않았다.
- 발견한 오류: 낙폭을 `irpHistory`의 마지막 두 값으로 판단해 운용창 진입 시 지난 턴의 결과를 보았고, 정산 후에는 입출금도 낙폭에 섞였다.
- 수정: 이번 턴 `ledger.marketEffects` 합계와 이번 턴 대기자금 이자를 턴 시작 IRP로 나눠 판정. 구 저장에 상품별 내역이 없으면 현재 턴의 합산 장부(`afterMarket - open`)를 사용한다. 이 구 저장 경로는 주문 결제 영향이 함께 포함될 수 있다. 목표 달성 우선순위·시장 충격 조건·5% 기준·승인 강도(1/3/3)·2초 휴식 반복은 유지했다.
- 회귀 테스트: 정산 전 당일 손실 감지, 전 턴 손실 후 회복, 입출금에 의해 손실 판정이 바뀌지 않음, 대기자금 이자/구 저장/잔액 0 경계를 검사했다. 기존 코드에서 3개 케이스 실패를 확인한 뒤 수정 후 전체 68파일·700테스트, 타입 검사·린트·빌드를 통과했다.
- Ego 390px 실제 게임 앱에서 엔진으로 생성한 별도 QA 체크포인트를 이어하기로 열었다. 평온·긴장·기쁨 각각 올바른 이미지와 강도(1/3/3)로 2회 이상 반복했고 전체 GameState는 값 기준 재귀 비교로 그대로였다. 사용자의 실제 판을 재현했다고 주장하지 않는다.
- `mood-recheck-qa.json`: 각 표정의 실제 WAAPI 키프레임·재생 시점·게임 상태 불변 검증. `mood-happy-check.png`, `mood-tense-check.png`: 별도 엔진 QA 판의 동작 중간 시점을 멈춘 시각 확인 자료.
- 일반 손익에도 기쁨·긴장을 표시하는 조건 확대는 사용자의 별도 선택을 기다리며 이번 수정에 포함하지 않았다.
