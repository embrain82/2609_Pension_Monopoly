# 캐릭터 표정 애니메이션 적용

2026-09-17 · 승인: 평온 1단계 / 긴장 3단계 / 기쁨 3단계.

## 적용

- 올리·원이·단지·달리·코리 모두 같은 승인 강도 적용. 기존 평온/긴장/기쁨 이미지와 판정 규칙 유지.
- 평온: 1.6초의 작은 호흡(가로 1%, 세로 2.5% 확대).
- 긴장: 0.7초간 칸 너비의 ±4% 좌우 흔들림과 ±2.5° 기울기.
- 기쁨: 1초간 칸 높이의 12%, 7.2% 두 번 점프, ±5° 기울기와 착지 탄성.
- 새 판 시작과 매 턴 도착 후 한 번. 주사위·이동·칸 공개 후 예약하며 안내창이 열려 있거나 말이 화면 밖에 있으면 보드가 보일 때까지 보류.
- 같은 턴 조회·스크롤·재렌더로 반복하지 않음. 이미 시작한 연출은 안내창/탭 숨김/캐릭터 변경/다음 이동 시 취소. 새로고침·이어하기는 이전 연출을 재생하지 않음.
- 앱 및 시스템의 움직임 줄이기, 캐릭터 끄기, 이미지 실패 시 정지 상태. 기존 2배속 설정에서는 재생 시간만 절반.
- 이동용 말 변환과 표정용 SVG 그룹을 분리. 금융 엔진, RNG, 저장 형식, 점수, 주사위, 도장, 칸 공개 규칙은 변경하지 않음.
- 그림자 필터를 최상위 SVG에만 적용해 점프가 잘리지 않으면서 원본 스트립의 옆 표정이 노출되지 않게 처리.

## 검증

- 전체 68개 파일 / 696개 테스트 통과. 타입 검사·린트·프로덕션 빌드 통과.
- 연출 수명주기 신규 8개 테스트: 안내창/이미지/화면 가시성 대기, 한 번 재생, 캐릭터 변경과 중단, 이어하기, 움직임 줄이기, 이미지 실패.
- Ego 브라우저 390px 새 게임 → 첫 주사위 → 운용창 X → 포트폴리오 왕복: 시작/도착 각 1회, 왕복 중 추가 재생 0회, 금융 상태 변화 0건.
- 새로고침 → 이어하기: 추가 재생 0회, 게임 상태 재귀 비교 동일(직렬화 키 순서 제외).
- 실제 게임 렌더러로 5캐릭터 × 3표정 × 4너비(320/390/768/1440px), 각 21시점 검사. 이름 침범 0건, 보수적인 SVG 사각형 기준 최소 간격 2.84px.
- 원본 스트립을 자르는 내부 SVG의 overflow:hidden / filter:none, 바깥 SVG의 overflow:visible 확인. 전체 캐릭터 캡처로 시각 검증.
- 실제 직접 플레이와 별도 시각 검사 fixture를 구분. happy/tense 강도와 이름 간격은 fixture에서 검사.
