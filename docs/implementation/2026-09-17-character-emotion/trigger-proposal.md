# 캐릭터 표정 작동 기준 변경 제안

2026-09-17 · 사용자 승인 후 구현 완료 · 세부 검증은 trigger-implementation.md 참조

## 추천 방향

칸 공개 직후, 도착 효과와 이번 턴 실제 운용 손익을 함께 판단한다. 한 번에 표정 하나와 이유 하나를 보여주며, 보드가 보이는 동안 같은 표정을 반복한다. 평온 1단계·긴장 3단계·기쁨 3단계, 반복 사이 2초 휴식은 유지한다. 올리·원이·단지·달리·코리에 동일한 기준을 적용한다.

## 운용 손익 기준

| 표정 | 제안 조건 | 이유 문구 예시 |
| --- | --- | --- |
| 기쁨 | 이번 턴 실제 운용수익률 +1.0% 이상 | 이번 턴 운용 +1.4% |
| 긴장 | 이번 턴 실제 운용수익률 -1.0% 이하 | 이번 턴 운용 -1.2% |
| 평온 | -1.0% 초과, +1.0% 미만이고 별도 사건/보상 없음 | 차분하게 다음 선택을 준비해요 |

- 수익률은 `(이번 턴 상품별 실제 운용 손익 합계 + 이번 턴 IRP 대기자금 이자) / 턴 시작 IRP 평가액`으로 계산한다. 연환산이나 게임 시작 이후 누적 수익률이 아니다.
- 추가납입·출금·세액공제 환급·단순 매수/매도 원금 이동을 운용 수익에 포함하지 않는다. 보유분에 실제 반영된 상품 보수·예금 약정 등 기존 장부를 사용한다.
- 시장 뉴스가 호황이거나 금리가 내렸다는 이유만으로 기쁨을 선택하지 않는다. 내 계좌의 실제 결과를 본다. 시장 충격 플래그도 단독 긴장 조건에서 제외한다.
- 구 저장에 실제 상품별 손익이 없으면 수익률을 추정해 표정을 붙이지 않고, 확인 가능한 칸 효과를 사용한다.

## 칸 도착 기준

| 칸/상황 | 표정 | 실제 발생 확인 |
| --- | --- | --- |
| 연말정산 | 기쁨 | 해당 칸 도착으로 환급액이 0원보다 클 때. 환급 0원은 보상 반응 없음 |
| 운용지시 | 기쁨 | 도착 효과로 행동 기회가 2회 주어졌을 때 |
| 제도 안내·성향 점검·분산 광장 | 기쁨 | 도착 시 이해 점수가 실제로 증가했을 때. 단순 점검 실패는 자동 긴장으로 만들지 않음 |
| 생활 사건 | 긴장 | 실제로 해결해야 할 사건이 열렸을 때. 첫 턴·마지막 턴·발생 한도 등에 의해 사건이 생기지 않으면 제외 |
| 예금·채권·ETF·TDF·혼합형·시장 뉴스·금리 전망·은퇴 전망 | 운용 손익 기준 | 상품 종류나 칸 이름 자체를 좋고 나쁨으로 구분하지 않음 |
| 리밸런싱 | 운용 손익 기준 | 도착은 보상 기회 안내뿐이므로 미리 보상받은 것으로 처리하지 않음 |

도착 칸 보상은 `tileEffects` 중 `tileIndex === position`인 효과만 대상으로 한다. 연말정산을 통과하며 받은 환급을 다른 도착 칸의 보상으로 설명하지 않는다. 예정된 생활 사건은 해당 턴 실제 해결 대상이면 긴장 사유로 사용할 수 있다.

목표는 처음 달성한 턴에 기쁨 후보로 추가한다. 이후에는 목표를 계속 충족하더라도 매 턴 운용 손익과 사건을 다시 판단한다. 기존의 목표 최초 달성 기록을 재사용하며 점수나 달성 조건을 변경하지 않는다.

## 조건이 겹칠 때

1. 해결 전 생활 사건이 있으면 긴장: `생활 사건이 생겼어요`.
2. 실제 운용수익률이 -1.0% 이하이면 긴장.
3. +1.0% 이상이면 기쁨.
4. 실제 칸 보상 또는 이번 턴 최초 목표 달성이 있으면 기쁨.
5. 나머지는 평온.

큰 손실과 보상이 겹쳐도 표정을 빠르게 번갈아 재생하지 않는다. 보상 내용은 기존 안내에 남긴다. 사건을 해결하면 사건 조건을 해제하고 같은 턴의 운용 손익/보상 기준으로 다시 판단한다. 예를 들어 운용 +2%와 생활 사건이 겹치면 해결 전 긴장, 해결 후 기쁨이다. 표정은 선택을 대신하거나 거래를 권유하지 않는 연출이다.

## 화면 흐름

1. 주사위 및 말 이동 → 최종 도착 칸의 색과 내용 공개.
2. 표정과 짧은 이유를 약 1.2초 보여준 뒤 기존 생활 사건/운용창 진행. 사용자가 운용 버튼을 먼저 누르면 바로 진행할 수 있게 한다.
3. 이유는 말과 칸 이름 위에 겹치지 않도록 기존 보드 하단 상태 영역에 한 줄로 표시한다. 클릭/호버가 없어도 이해 가능하게 한다.
4. 창을 닫고 보드로 돌아오면 현재 표정을 즉시 반복한다. 다음 주사위 이동 시 이전 표정을 종료하고 다음 도착 결과로 교체한다.
5. 움직임 줄이기에서는 표정 이미지와 이유만 표시하고, 추가 애니메이션 대기를 생략한다. 창 뒤·탭 숨김·보드 화면 밖에서는 반복을 멈춘다.

## 기준 선택 근거

현재 엔진에서 5개 투자자성향 × 4개 시장 시나리오 × 6개 시드 = 120판, 1,440턴을 계산했다. 매 턴 기존 구성을 유지하고 생활 사건은 생활자금으로 처리하는 비교 경로다. 최신 금융·디폴트옵션·추가납입 속도 규칙을 사용했다. 아래는 칸 보상·생활 사건 우선순위를 적용하기 전 **운용 손익만의 분포**이며 실제 사용자 플레이 빈도를 보장하지 않는다.

| 손익 기준 | 기쁨 | 긴장 | 평온 |
| --- | ---: | ---: | ---: |
| ±0.5% | 496턴 (34.4%) | 308턴 (21.4%) | 636턴 (44.2%) |
| **±1.0% 추천** | **257턴 (17.8%)** | **228턴 (15.8%)** | **955턴 (66.3%)** |
| ±1.5% | 171턴 (11.9%) | 186턴 (12.9%) | 1,083턴 (75.2%) |

±1.0%는 시장 손익 반응이 지나치게 잦지 않으면서 기존 긴장 기준인 -5%보다 쉽게 확인할 수 있다. 이 경로의 안정형은 시장 기준 기쁨·긴장이 0회여서, 칸 보상을 함께 반영하는 것이 다양한 성향으로 플레이할 때의 표현에 필요하다. 모든 성향에 동일 기준을 쓰며 캐릭터 외형에 따라 기준을 다르게 두지 않는다.

## 승인 후 구현 순서

1. `src/ui/avatars.ts` 주변에 표정과 이유를 함께 반환하는 순수 판정 함수를 두고, 게임판과 은퇴설계 카드가 동일한 결과를 사용하게 한다.
2. 현재 턴 장부·도착 효과·생활 사건·기존 최초 달성 기록으로 판정한다. 화면 연출 상태는 금융 GameState와 분리한다.
3. 칸 공개 완료와 모달 표시 사이의 약 1.2초 연출 구간을 연결한다. 반복 플레이어는 기존 승인 강도를 그대로 사용한다.
4. ±1% 경계, 칸 보상 0/양수, 생활 사건 미발생/해결, 음수 수익과 보상 동시 발생, 목표 달성 다음 턴, 구 저장을 검증한다.
5. 모바일에서 칸 공개 → 표정 → 운용창 → X → 반복, 다음 턴 교체, 이어하기, 움직임 줄이기를 직접 확인한다. 추가 연출 중 중복 클릭·탭 숨김이 거래/이동/점수를 중복 처리하지 않는지 확인한다.

검토 항목: **손익 ±1% / 실제 칸 효과 반응 / 생활 사건·손실 우선 / 도착 후 약 1.2초 노출**.
