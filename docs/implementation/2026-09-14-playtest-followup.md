## 이동과 복원 증거

[프레임별 이동 기록](2026-09-14-playtest-followup/movement-trace.json)에서 주사위가 보이는 **176프레임 모두** 게임판이 하단 버튼 위 가시 영역 안에 있었습니다. 말은 1→2→3번 이동 인덱스를 순서대로 지나고 이동 중 추가 스크롤이 없었습니다. 이동 도중 새로고침하면 실행 전 0턴 상태로 복원되어 추가 시장·급여가 발생하지 않았습니다. 시스템 동작 줄이기도 즉시 1턴으로 한 번만 진행됐습니다.

추가로 위험 안내 Tab 순환·Esc 취소, 확인 전/후 새로고침, 포트폴리오 왕복, 첫 납입 후 두 번째 운용, 점수 상한 무안내, 정산 X 후 주사위 우회 차단을 실제 브라우저에서 확인했습니다.

검증 범위는 **Ego Lite의 Chromium과 모바일 화면 에뮬레이션**입니다. 실물 iPhone의 Safari 및 실제 스크린리더 음성 출력은 이번에 확인하지 않았습니다. 720×500 검증은 1440×1000 화면의 200% 확대에 대응하는 리플로우 조건이며 실제 브라우저 확대 조작 검증과 구분합니다.
