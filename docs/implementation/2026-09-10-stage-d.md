# D 단계 · v1.4.0

## 적용 범위

⑥ 시장·상품, ⑨ 승리조건·재플레이, ⑩ 학습·운영. C의 주사위 합 자동 이동과 X 닫기 유지. 디폴트옵션 재설계는 기존 별도 백로그 유지.

새 UI 게임은 campaign 데이터를 가진 D판이다. 엔진 createGame의 scenario 옵션 생략은 기존 C 규칙 재현용이다. 기존 c1/c2 진행 저장은 campaign 없이 그대로 완료 가능하다. D는 기존 저장 키/형식을 확장하며 장 분기 상태도 저장한다.

## 시장과 시간

- classic / inflation / recession / recovery 네 프리셋. 원래 4국면·2~3충격·시드 주사위는 유지하며 국면 전이·물가·주식 드리프트·신호 오경보 비율을 조정한다.
- 1턴=물가와 생애주기 계산상 가상 3개월, 12턴=3년(2026→2029). 물가 표시는 연율이며 분기 지수는 (1+물가/100)^0.25.
- 납입·공제한도는 한 판 합산으로 압축한다. 한 바퀴를 실제 과세연도로 간주하지 않는다. 연말정산 칸은 환급 연출.
- 상품 수익률·보수는 턴당 교육용 값. 기존 예금은 가입 건별 고정금리, 신규 조건만 현재 금리 영향. 만기는 기존 현금화 규칙 유지, 디폴트옵션 자동 연결은 보류.
- TDF 2029 주식 비중은 45→25% 선형 축소. 예금 15%, 나머지는 단기·장기채 균등. 해당 턴 수익에는 턴 시작 비중, 턴 종료 주식 노출에는 축소 후 비중을 사용. 법정 위험자산 분류와 별개.
- 생활비 사건만 물가로 조정, 보너스·퇴직급여 금액은 고정. 사용자 표시와 실제 차감은 같은 inflatedEvent를 사용한다.
- 전망대는 현재 금리·국면에서 새 시드로 조건부 표본 생성. 실제 미래 경로 미참조, 표본 20개의 p10/p90이며 보장 구간 아님. 예금 기존 약정 유지. 미결 매수는 편입된 것으로 단순 추정하며 실제 결제 시차와 차이 있음.

## 성과·미션

시작 전에 연금 목표 / 순생활자금 1,800만원 / 실질 운용지수 100 미션을 선택한다. 목표·성향·미션은 게임 중 고정. 주간 도전은 classic, pension, balanced, 월 50만원 고정.

별은 미션 달성 1개, 생활 완충 및 미지급 0원까지 2개, 성향 낙폭 예산까지 3개. 상품 개수나 고정 목표비중 복제가 별 필수 조건이 아니다. 보조 점수 100점 체계는 비교용으로 유지하며 큰 결말은 미션을 따른다. 지식은 기본 4+정답당 2(최대 16)-규칙 위반 페널티. 반복 거래·리밸런싱·단순 방문 자체에 지식 점수 없음.

운용지수는 시장 전후 구간 비율 연결 후 매매·정산 영향을 기말 원본으로 보정한다. 순입출금은 모든 cashFlows를 포함한다. 정밀 TWR이 아닌 명시된 교육용 보정식이다. 시장 낙폭은 이 지수의 최고점 대비로 계산하여 외부유입에 의한 고점 왜곡을 줄인다. 결과는 자산 증가율·운용지수·물가 보정·순입출금을 분리한다.

동일 입출금 기준은 시작 상품 비중을 매 턴 복원하는 마찰 없는 지수이다. 상품 보수 반영, 실제 매매 수수료·결제 지연·예금 약정 재현 안 함. 전체 경로 고스트는 생활사건 선택과 납입까지 다른 비교로 구분한다. 기준 지수 우위가 실제 실행 가능한 초과 성과를 증명하지 않는다.

## 복기·학습

3턴씩 4장, 완료 턴별 시장/행동/순입출금/비용/보유를 기록한다. 결과에서 3·6·9턴 끝부터 분기 연습 가능. 미래를 본 뒤의 연습이므로 최고 기록·컬렉션·업적 집계 제외. 복기 JSON은 사용자가 파일로 내려받으며 외부 전송 없음. 현재 결과의 정량 근거를 제시하고 거래 횟수만으로 가장 좋은 결정이라 단정하지 않는다.

기존 20문항 표현 보완 + DB/DC/IRP, 매도/인출, 가격확정/결제, 물가, TDF 경로 5문항 추가. 관련 행동 학습은 정산의 선택형 버튼으로 제공. 25카드에 목표·출처·검수일·게임 가정·관련 행동을 묶었다. build-learning-guide.ts가 같은 JSON에서 learning-guide.html을 생성하며 build 시 실행한다.

- 시장·가격·TDF·입출금 중립·낙폭·목표 고정·학습 연결·분기 저장 테스트.
- UI 시나리오 변경 후 설정 펼침 유지, 정산에서 퀴즈 왕복, 6턴 분기 후 재시작 복원.
- 20시드 × 4시나리오 × 5성향 × 11전략 = 4,400판. 종료/미결주문/유한 지수/12턴 기록 검사. 결과 stage-d-matrix.json.
- 미션 승률은 표본 시드에서만 비교하며 재미나 우월 전략 일반화를 보장하지 않는다. 실제 초보자 6~8명 사전/사후·1주후 학습 검증은 참여자 확보 후 운영해야 한다.
