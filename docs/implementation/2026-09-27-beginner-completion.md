## 계산과 호환성

금융 엔진, 주문, 예금 만기, 위험 한도, 별·도장·점수 산식은 변경하지 않았습니다. 기존 종합점수는 연금 목표 50점·안정성 30점·학습 20점입니다. 새 캠페인 판의 학습은 기본 4점+퀴즈 최대 16점, 구판은 기존 이해·리밸런싱 보너스와 상한·감점을 그대로 적용합니다. 이번 변경은 기존 반영을 사용자가 알 수 있도록 연결합니다.

원인별 손익의 ‘기타 가격 변동·충격·상하한 조정’은 전체 가격 변동에서 채권 이자와 금리 효과를 제외한 나머지입니다. 개별 요인의 정확한 기여를 추정해 표시하지 않습니다. 예금은 가입 건별 약정·만기를 반영한 실제 합계를 사용합니다. 모든 숫자는 게임 턴당 값이며 실제 연이율과 구분합니다.

필수 만기 통지와 퀴즈 건너뛰기 확인 흐름을 유지했습니다. 추가납입 미리보기는 실행 전/후 잔액을 비교하며 다른 미결제 주문을 새 납입으로 표현하지 않습니다.
