# 단계 B 구현 · 2026-09-10

범위: ⑧ 디폴트옵션 상태 관리, ⑦ 성향·캐릭터 분리, 효과음 활성화 문제 수정.
기준 버전: main 8539063 / v1.1.0-p0.

## 변경

- 자금별 원장: 예금 만기/신규가입 초기입금/일반 추가납입/이전/매도 대금을 구분한다. 매수·인출 시 실제 소비한 원장도 차감한다.
- 만기된 가입 건만 현금화하고, 2턴 뒤 통지·추가 1턴 뒤 자동 주문한다. 신규가입 초기입금은 첫 통지 후 1턴이다. 일반 추가납입·매도·이전은 이 게임의 자동 적용 대상이 아니다.
- 미지정은 자동운용하지 않는다. 현금 유지 지시는 현재 자금의 적용을 중단한다. 옵션 변경 시 다시 통지하고, 미결제 주문이 있으면 중복 주문을 피하도록 대기한다. 마지막 턴의 정산 전용 시간은 통지 대기를 임의로 앞당기지 않는다.
- 「그대로 두기」, 「옵트인 실행」, 「옵트아웃 실행」, 「현금 유지 지시」를 분리했다. 옵트아웃은 기존 일반 보유분을 보존하고 지정옵션 편입분만 공통 매도 엔진으로 환매한다.
- 4개 가상 승인형 포트폴리오의 고정 구성 계약과 편입 금액을 추적한다. 편입분만 규제 한도에서 제외하고 일반 ETF 직접 매수는 70% 한도를 유지한다. 가상 상품으로 실제 승인 상품이 아니며, 기초자산의 손실·결제 위험을 없애지 않는다.
- 5성향의 시작/목표 구성, 생활자금·낙폭 과제를 구분했다. 성향 점검·체크리스트·결과·이정표·HUD가 같은 기준을 사용한다. 목표로 돌아가기 위해 옮겨야 하는 구성 비중 10%p 이내를 정렬 기준으로 삼는다.
- 캐릭터 외형은 별도 선택이다. 재진단이 캐릭터를 바꾸지 않고, 컬렉션은 선택한 동물로 기록한다. v6까지의 저장은 v7로 이전하며 기존 외형·기록·설정을 보존한다.
- 결과에 별도 통제 실험을 추가했다. 동일 초기입금·시드·성향·생활사건·추가납입 0 조건에서 직접 리밸런싱 / 통지 후 자동운용 / 미지정 현금을 비교한다. 실제 플레이어의 행동을 복제한 반사실 결과와 구분해서 표시한다.
- 효과음: 기존 코드는 비동기 AudioContext.resume()을 기다리지 않고 running이 아니면 음을 버렸다. 이제 활성화 완료 후 재생하고 suspended/interrupted 상태를 복구한다. 끄거나 탭을 이동하면 대기·재생 중인 음을 취소한다. 생성 실패·차단·미지원도 처리하고 설정에 테스트 버튼과 재생 상태를 표시한다.

## 명시적 가정·남은 범위

- 절차에 한해서 1턴=2주로 압축한다. 시장 시간·세액공제의 1년분 한도·55세 이후 수령 계산은 별도 모형이다. 은행별 신규 부담금 운영 실무를 일반 추가납입 전체에 확장하지 않는다.
- 가상 포트폴리오는 주문 시 고정 구성대로 편입하며 구성품별 가격을 추적한다. 실존 승인 포트폴리오의 내부 자동 리밸런싱·수수료 전체를 재현하지 않는다.
- 과거 점수 기록은 보존한다. 버전 간 최고기록 분리, 현금흐름을 고려한 낙폭, 승리 조건 전면 개편은 ⑨에 남아 있다.
- 소리 검증은 재생 명령과 오디오 상태까지다. 기기 스피커·헤드폰 실제 청취와 탭 음소거는 자동 검증하지 못했다. 배경음악은 없으며 효과음만 제공한다.
- 다음 구현 순서: ④ 보드·캐릭터 렌더링 → ③ 경로·미션 → ⑤ 턴 진행·저장 → ⑥ 시장 모형 → ⑨ 평가·재플레이 → ⑩ 학습·매뉴얼 종합 검증.
