## 반영 내용

- **FB-017:** 기존 25개 주제 ID·해금·점수·출제 빈도를 유지하면서 질문과 보기·해설을 상황형으로 교체했습니다. 물가와 구매력, 금리와 채권, 유동성, 분산, 납입과 공제, IRP 인출, TDF, 디폴트옵션 등을 다룹니다. 정답 위치는 9/8/8개로 분산했습니다. 새 판은 새 은행, 구 판은 기존 질문과 정답을 사용합니다.
- **FB-018:** 일반 예금과 예금 100% 옵션의 만기 원리금을 IRP 대기자금으로 이동합니다. 다음 턴에 사전지정 통지를 만들고, 안내가 실제 화면에 표시된 다음 턴부터 남은 대상액으로 자동주문합니다. 통지를 생성했어도 아직 보여주지 않았다면 주문하지 않습니다.

## 금융 처리와 게임 표현

실제 만기 후 4주 무지시 → 통지 → 추가 2주 무지시 절차와 게임의 턴 압축을 구분해서 표시합니다. 통상 게임 흐름은 만기 T → 통지 T+1 → 자동주문 T+2이며 실제 주 수나 현실의 시간 경과와 같지 않습니다.

- 만기 대상액은 IRP 현금에 이미 포함된 하위 장부입니다. 평가액이나 입금·수익에 한 번 더 더하지 않습니다.
- 턴 시작 현금의 교육용 대기 이자를 대상액에도 배분합니다. 같은 턴에 새로 만기된 금액에는 그 턴의 현금 이자를 중복 부여하지 않습니다.
- 일반 매수·인출의 현금 사용은 오래된 만기 건부터 차감합니다. 추가납입·매도 대금 등 일반 현금을 자동운용 대상에 편입하지 않습니다.
- 자동주문은 직접 옵트인과 같은 상품 구성·기준가·결제 계산을 사용합니다. 행동 횟수, 직접 매수 보상 횟수는 소비·증가하지 않습니다. 원 단위 주문 후 소수 잔액은 일반 현금으로 남습니다.
- 혼합 옵션 내부 예금은 새로운 약정 금리로 재예치하는 가상 계약입니다. 모든 현실 상품의 공통 규정이라고 설명하지 않습니다.
- 사전지정 변경은 매매가 아닙니다. 대기 중인 건의 통지를 다시 시작합니다. 지정 해제, 다른 옵션 보유, 미결제 주문, 매수 조건 미충족은 자동주문을 보류하고 사유를 표시합니다.
- 만기자금 상세 안에서만 「현금 유지 지시」를 제공합니다. 해당 건의 대기만 종료하며 행동 1회를 사용합니다. 상위 운용 메뉴 항목 수는 늘리지 않았습니다. 「이번엔 그대로」는 무지시 대기를 계속합니다.
- 만기·통지·주문 안내가 있으면 정산 자동 진행 설정이 켜져도 직접 다음으로 넘깁니다.
- 12턴 종료 후에는 새 자동주문을 만들지 않습니다. 기존 접수 주문의 종료 정산은 기존 방식대로 처리합니다.

새 금융 규칙 `2026-09-16-g`, 진행 저장 `c5`, 금융 상태 `f2`, 퀴즈 버전 `2026-09-16-situations`를 사용합니다. 구 저장 판은 자동 업그레이드하지 않습니다. 새 규칙을 플레이하려면 **새 판**을 시작합니다.
