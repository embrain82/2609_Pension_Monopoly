# 올원프렌즈 게임 캐릭터 — v1.11.0

검토한 시안을 바탕으로 플레이어 캐릭터를 올리·원이·단지·달리·코리로 교체했다. 게임 시작 화면과 설정에서 그림 카드를 눌러 선택하며, 선택된 카드에는 녹색 테두리와 `✓ 선택됨`을 함께 표시한다.

## 적용 범위

사용자 후속 검토에 따라 캐릭터 선택 아래의 작은 보드 미리보기 그림은 제거했다. 캐릭터 선택 카드에서 외형과 선택 상태를 확인한다.

- 게임판의 말, 자산 정보 영역, 캐릭터 컬렉션, 최종 결과에 같은 캐릭터를 사용한다.
- 평온·긴장·기쁨 3가지 포즈를 기존 시장 충격·목표 달성·결과 판정과 연결한다.
- 포즈별 중심과 발 위치를 SVG 표시 영역에서 맞춰 표정 전환 시 위치 차이를 줄였다. 게임판 이름을 덜 가리도록 말 크기와 그림의 세로 위치를 조정했다.
- 캐릭터 표시를 끄면 이름 카드와 기존 `나` 말을 사용한다. 이미지 로딩 오류가 발생하면 색 원 안에 캐릭터 이름을 보여준다.
- 키보드 Tab/Space/Enter로 카드를 선택할 수 있다. 선택과 투자성향은 별개이며, 캐릭터 변경으로 금융 상태·난수·점수를 바꾸지 않는다.

## 저장 호환

기존 외형 슬롯을 유지한다. 내부 키 이름이 투자성향과 같아도 외형 선택은 별도로 저장한다. 이전 캐릭터의 완주 횟수와 최고 별 기록은 대응하는 새 캐릭터가 이어받는다.

| 저장 슬롯 | 새 캐릭터 |
|---|---|
| stable | 올리 |
| stableGrowth | 원이 |
| balanced | 단지 |
| growth | 달리 |
| aggressive | 코리 |

두 주사위의 입체 모양·굴리기, 칸별 이동·착지 애니메이션과 금융 규칙은 유지한다. 고정 안내자인 앵커·코치는 이번 플레이어 캐릭터 교체 범위에 포함하지 않았다.

## 이미지 산출물

- 생성 방식: **builtin imagegen**. 검토 시안과 NH농협은행 공식 캐릭터 이미지를 참고한 게임용 파생 이미지다.
- 공식 참고: [NH농협은행 캐릭터 소개](https://www.nhbank.com/goSubPage.do?srchGb=KO_NHPR_17&srchSiteGb=KR).
- 게임용 파일: [public/assets/characters/allone](../../../public/assets/characters/allone).
- 각 PNG: 2172×724, RGBA, 가로 3포즈. 합계 4,539,127바이트(약 4.54MB).
- 로컬에서는 이미지 픽셀을 수정하지 않았다. 생성 도구로 실제 투명 알파를 확보한 파일을 그대로 복사했다. 체크무늬가 배경으로 구워진 중간 결과는 제외했다.
- [최초 생성 프롬프트](image-prompts.json), [후처리 요청 요약](extraction-prompts.json), [최종 원본 식별자](asset-sources.json), [알파·해상도·해시 검사](asset-qa.json).

## 검증

- 전체 자동 테스트: **63개 파일, 651개 테스트 통과**. 카드 선택·저장, 기존 컬렉션, 금융 상태 불변, 이미지 오류 대체 표시, 캐릭터 표시 끄기를 추가 확인했다.
- TypeScript 검사, ESLint, 프로덕션 빌드, `git diff --check` 통과.
- Ego Chromium에서 진단→시작, 5종 선택, 키보드 Space 선택, 저장·새로고침·이어서 플레이를 확인했다.
- 320·390·768·1440px 화면 폭에서 선택 카드 위치를 검사했다. 문서의 가로 넘침은 없었다.
- 일반 모션으로 주사위 2개 생성과 코리의 6칸 이동을 관찰했다. 각 이동 칸에서 실제 Web Animations 실행을 확인했다.
- 동작 줄이기를 켜고 12턴 완주→연금(20년) 수령 선택→코리 최종 결과까지 진행했다.
- 세부 브라우저 결과: [browser-qa.json](browser-qa.json).

브라우저 화면 캡처가 시간 초과되어 최종 합성 화면의 스크린샷 검증은 완료하지 못했다. 실제 iOS Safari 기기 검증도 수행하지 않았다. 브라우저 DOM·이미지 디코딩·입력·애니메이션 실행 검증과 구분한다. 모바일 최초 로딩에서는 이미지 약 4.54MB가 필요하며, 현재 파일은 원본 품질을 유지한다.
