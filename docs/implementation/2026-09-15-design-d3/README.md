정산의 `내가 한 일`은 상세에서 기본 화면으로 옮겼다. 전체 상품의 시장 예시, 비교 지수, 고스트 비교, 칸 효과, 다음 판단은 기존 상세에서 볼 수 있다. 학습과 최종 주문 정산 안내는 다음 진행 버튼보다 먼저 노출한다.

## 수령 선택의 확정 시점

- `choose-payout`은 화면의 임시 비교 선택만 바꾼다. 실제 자산·로그·점수·최고 기록·완주 횟수는 그대로다.
- `confirm-payout`의 **이 방식으로 결과 보기**를 누르면 기존 `choosePayout` 엔진을 한 번 호출한다. 선택이 없으면 확정 버튼은 비활성화하고 사유를 연결한다.
- 결과에서 다시 비교할 때는 **확정된 방식**과 **비교 중인 선택**을 구분한다. X/Esc로 닫으면 원래 확정 상태를 유지한다. 처음 마무리할 때는 기존처럼 수령 방식을 확정해야 결과로 진행한다.
- 확정 전 새로고침은 자산이나 점수를 바꾸지 않는다. 임시 선택은 메모리에만 두므로 다시 선택해야 한다는 설명을 버튼 아래 표시한다. 게임 및 체크포인트 스키마를 확장하지 않았다.
- 결과에서 방식을 재확정해도 완주 횟수와 컬렉션은 중복 집계하지 않는다. 기존 최고 기록 갱신 규칙은 유지한다.

## 구현

`quiz-view.ts`, `settlement.ts`, `payout-view.ts`, `result-summary.ts`의 기존 렌더러와 `app.ts`의 이벤트를 연결했다. 신규 `design-d3.css`는 D3 화면에 범위를 제한한다. 거래·시장·점수 엔진, 저장 구조, 주사위 연출·말 이동은 수정하지 않았다.

`public/assets/design-a1/journey.jpg`는 선택한 12-4 시안의 `docs/design/2026-09-15-play-flow/assets/journey-a.jpg`를 그대로 사용한다(1536×1024). 기존 A-1 제작 때 생성한 NH 올원프렌즈 참고 AI 디자인 자산이며 공식 배포 이미지와 구분한다. 추가 이미지 생성은 하지 않았다. 캐릭터 표시 설정과 그림 로딩 실패 시 대체 표식을 지원한다.

## 직접 브라우저 확인

Ego Browser TaskSpace 6의 별도 로컬 테스트 주소 `127.0.0.1:5193`, `localhost:5193`를 사용한다. 사용자의 운영 저장을 지우지 않는다. 화면별 상태는 엔진으로 만든 정상 체크포인트를 먼저 검증한 뒤 불러오며, 새 판의 실제 12턴 플레이와 구분해 기록한다.

- [반응형 기록](responsive-qa.json): 퀴즈·정오답·상한·정산·충격·최종 정산·구 저장·수령·세 미션 결과·미달의 13개 상태 × 5개 크기 = **65개 유효 검사 통과**. 가로 넘침 없음, PC 좌우/모바일 세로 배치, 접근성 설명 대상 존재, 조회 전후 저장 상태 유지. 초기 320px 모바일 설정이 실제 336px로 확장된 1회는 유효 검사에서 제외하며 원본에 남겼다. 320px는 좁은 CSS 뷰포트 검사다.
- [12턴 이어하기](resume-final-qa.json): 실제 새로고침 → 이어서 플레이 후 게임 객체 전체의 깊은 비교가 일치했다. [5턴 초기 시도](resume-qa.json)는 개발 서버 갱신과 클릭이 겹쳐 통과 근거에서 제외한다.
- [PC 12턴 완주](desktop-play.json): 실제 주사위·버튼 클릭으로 12턴을 진행하고 퀴즈 15개, 수령 선택 후 명시적 확정, 최종 결과까지 확인했다. 결과에서 일시금으로 임시 선택한 후 X 취소하자 기존 연금 수령을 유지했고 완주 횟수도 1회였다. 5턴 개발 서버 갱신 및 12턴 이어하기를 포함한다. [모바일 390×844 완주](mobile-play.json)는 처음 두 문제를 풀고 이후 퀴즈는 안내 확인 후 건너뛰는 경로를 확인했다. 두 판 모두 동작 줄이기·2배속이며 주사위 동작 자체는 유지한다. [12턴 금융 상태 대조](play-comparison.json)에서 모든 턴의 자금·보유·주문·세금 재원·시장 경로가 PC와 같다. PC는 105단계, 모바일은 68단계 UI 클릭·관찰 기록이며 최종 완주 횟수는 각각 1회와 2회다.
- 완주 로그에는 대조에 사용한 금융·학습 필드와 전체 게임 상태의 SHA-256을 남겨 중복 저장 기록을 줄였다. 전체 게임 객체가 일치하는지의 검사는 별도 테스트와 이어하기·배포 상호작용 기록에 있다.
- [배포본 개별 상호작용](interaction-qa.json): 실제 미리보기에서 답하기 전 근거 숨김, 정답 후 해설 초점/근거 공개/답안 비활성화, 엔진 전체 상태 일치, 새로고침 후 해설·게임 복원, 정산 복귀를 확인했다. 수령 임시 선택과 새로고침도 게임 객체 전체가 같으며 미확정 상태·완주 횟수 0회를 유지한다.
- **시각 검증 대기**: Mac 잠금으로 `Page.captureScreenshot`이 시간 초과했고 네이티브 도구도 잠금 상태를 확인했다. 화면 캡처·색/간격의 육안 확인과 애니메이션 관찰을 완료했다고 표시하지 않는다. DOM 배치 검사는 스크린샷 검증을 대체하지 않는다.
