# 모바일 정산 레이아웃 수정

사용자 캡처에서 정산 카드의 제목·설명이 오른쪽으로 몰리고, 변화 차트의 막대가 좁아지며 별도 파란 사각형이 나타나는 문제를 수정했다.

## 원인과 수정

- `main.css`의 예전 `.settle-split` 손익 설명 스타일이 D3의 같은 이름을 쓰는 전체 패널 레이아웃에도 적용됐다. 오른쪽 정렬·굵은 글씨가 자식에게 상속되고 `.market::before`가 차트 행에도 사각형을 생성했다. 더 이상 사용하지 않는 예전 스타일을 삭제했다.
- `playtest.css`의 압축 차트가 항목명·막대·금액을 한 줄 세 열로 배치하면서 모바일에서는 막대가 약 74px까지 줄었다. 항목명과 금액을 윗줄, 공통 0축 막대를 다음 줄 전체 너비로 배치했다. 금액은 줄바꿈 없이 오른쪽 정렬하고 행 간격을 확보했다.
- 엔진, 정산 수치, 저장 형식 및 게임 규칙은 수정하지 않았다.

## 검증

- Ego 브라우저에서 실제 엔진으로 생성한 손실·200만원 납입·거래 0원 정산 저장을 불러와 재현했다. 수정 전 오른쪽 정렬, 글꼴 굵기 800, 시장 행의 불필요한 `::before` 사각형을 확인했다.
- 수정 후 제목과 설명의 기본 왼쪽 정렬, 기본 본문 굵기, 사각형 제거, 막대 전체 너비, 항목과 금액 간 비겹침을 확인했다.
- 375·390·430·768·1024·1440px에서 카드 내용의 수평 넘침 없이 통과. 320px 요청에서는 브라우저의 실제 레이아웃 뷰포트가 336px로 측정돼 결과를 구분해 기록했다. iPhone Safari 실기기 검증은 포함하지 않는다.
- 관련 테스트 5개 파일 / 44개 테스트 통과. ESLint 및 프로덕션 빌드(TypeScript 검사 포함) 통과.
