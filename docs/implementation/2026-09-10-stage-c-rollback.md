# C 단계 조정 · v1.3.1

사용자 요청: 운용 창은 X 닫기만 표시하고 중복된 취소 문구 버튼 삭제. 매 턴 경로 선택과 경로 토큰 롤백.

## 변경과 영향

- 주사위 두 개 합으로 자동 이동. 짧은 경로, 토큰 소비, 첫 더블 토큰 보상, 지역 토큰 보상 제거.
- 지도와 방문·탐험 도장은 유지. 금융 자산·지식 점수·행동 횟수에 보상 없음.
- 운용 창의 X와 키보드 Esc는 거래 없이 닫기. 포트폴리오 조회·운용 복귀 유지.
- DOM 유지, 이동 애니메이션 취소 제어, 자동 저장, 간결한 턴 흐름 유지.
- 디폴트옵션 재설계는 기존 별도 백로그 그대로 보류.

## 저장 호환

저장 키 pension-road-play-c1을 유지하고 형식을 c2로 변경한다. 기존 c1의 자산·완료 턴·거래·미결 주문·탐험 기록·과거 로그를 보존하고 토큰/경로 선택 데이터만 제거한다. 과거 짧은 이동으로 이미 처리한 칸 효과는 소급 변경하지 않는다.

기존 경로 선택 또는 미완료 이동은 금융 처리가 시작되기 전 시점으로 복원한다. 다시 주사위를 누르면 같은 시드와 턴의 두 눈 합으로 이동하고 시장·급여는 한 번 처리한다. 새 형식도 이동 전에 체크포인트를 남기며 탭 숨김 시 애니메이션을 중단한다.

## 검증

- 기존 c1 경로 대기 및 거래 실행 후 저장 변환.
- 경로 창 없이 12턴 UI 완주, 결과 중복 집계 없음.
- 이동 중 탭 숨김·복원 후 위치/시장/급여 일치.
- 운용 닫기 버튼 한 개, 취소·포트폴리오 왕복 시 자산과 행동 보존.
- 200개 시드 합계 이동 완주.

검증 결과: 37개 파일의 398개 테스트 통과. typecheck/build/lint 통과. 실제 브라우저에서 주사위 후 자동 이동, X 단일 닫기, 포트폴리오 조회 후 재진입 확인.
