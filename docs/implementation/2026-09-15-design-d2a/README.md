일반 턴마다 새 안내창을 추가하지 않는다. 기존 속보가 열리는 조건은 그대로이며 일반 턴은 운용 메뉴의 접힌 시장 상세에서 확인한다. 상단에 보이는 ‘실제 시장 손익’과 펼쳐 보는 ‘전체 상품 시장 예시’를 구분한다. 시장 손익은 `ledger.afterMarket - ledger.open`으로 표시하므로 추가납입이나 매매 이후에도 과거 시장 구간 값이 바뀌지 않는다. 구 저장에 기록이 없으면 손익을 0원으로 추정하지 않는다.

생활 사건의 비활성 사유는 버튼 밖에도 남겨 읽을 수 있게 하고 `aria-describedby`로 연결한다. 사유와 ‘지금’ 문구가 같으면 한 번만 표시한다. 금액·선택 가능성·장기 영향은 기존 `lifeChoicesFor`를 사용한다. 운용 카드는 버튼 전체를 누를 수 있으며, 금융 상태는 기존 확정 동작에서만 변경한다.

## 게임판 크기 조정

아래 칸·중앙 숫자는 SVG `viewBox=700×700` 안의 글꼴 크기다. 화면에 표시되는 실제 크기는 보드 배율에 따라 달라진다. 작은 보드에서 과도하게 작아지지 않도록 모바일 칸 이름은 PC보다 조금 크게 유지한다. 칸을 선택하면 기존 상세 설명을 볼 수 있다.

| 요소 | D1 | D2a |
| --- | --- | --- |
| PC 칸 이름 | 20 / 굵기 650 | 16 / 굵기 550 |
| 모바일 칸 이름 | 20 / 굵기 650 | 18 / 굵기 550 |
| 칸 번호 | 16 | PC 13 / 모바일 14 |
| 중앙 일반 문구 | 19 | 16 |
| 중앙 국면·대기 | 31 / 굵기 750 | 25 / 굵기 650 |
| 중앙 금리 | 26 | 22 |
| 보드 제목 (CSS px) | PC 27 / 모바일 23 | PC 22 / 모바일 20 |

올리·원이는 안내 그림으로 유지하고 실제 이동 말은 기존 5종 동물이다. 실제 두 주사위의 점 눈·던짐·회전·착지·소리·칸별 이동·2배속·동작 줄이기를 유지한다. 이미지 추가나 금융 엔진·규칙·저장 스키마 변경은 없다.

## 검증

- 전체 **58개 파일 / 606개 테스트** 통과. 타입 검사·린트·프로덕션 빌드 통과. 생활 사건 중복 문구 정리 후 관련 **37개 테스트**와 타입·린트·빌드를 다시 확인했다. 마지막 뉴스 여백 수정 후 빌드도 통과했다.
- 최종 전체 재검사는 `npm test -- --maxWorkers=2`로 606개 통과했다. 앞선 기본 병렬 재검사에서 기존 12턴 UI 테스트 1건이 5초 제한을 넘었으며, 작업자를 2개로 제한한 재검사에서는 같은 테스트가 1.6초에 통과했다. 테스트의 내용·시간 제한은 변경하지 않았다.
- 새 8개 테스트: 원인→결과 표시 순서, 납입 후 시장 손익 불변, 실제 동결·마지막 턴 안내, 구 저장과 실제 노출 없음 구분, 생활 사건 3종의 엔진 선택 보존, 메뉴 조회·취소 무변경, 전액 매수 후 두 번째 행동 차단.
- [PC 12턴](desktop-play.json)과 [390×844 고정 화면 12턴](mobile-390-play.json)을 시작·생활 사건·납입·매수·매도·리밸런싱·교체·보유 유지·퀴즈 스킵 안내·수령 방식·결과까지 실제 UI 클릭으로 완주했다. 고정 화면 검증은 매 행동 시 실제 `innerWidth=390`을 기록한다. 두 판 모두 동작 줄이기 설정에서 흐름을 확인했다.
- 일반 주사위 연출·2배속에서도 별도 12턴을 진행했다([기록](mobile-play.json)). 보드 밖 스크롤 1,284.5px에서 굴리면 보드로 복귀하고 실제 3D 변환과 1+5=6칸 결과를 표시했다([주사위](dice-qa.json)). 별도 [말 이동 관측](token-movement-qa.json)에서 5→6→…→23→0→…→5의 칸별 이동을 확인했다. 일반 연출 판은 브라우저 크기가 일부 구간 바뀌어 고정 모바일 판과 구분한다.
- [9턴 새로고침·이어하기](resume-qa.json): 게임 전체 객체의 깊은 비교 일치.
- [반응형·사건 검증](responsive-qa.json): 6개 상태 × 5개 화면 크기(320×740, 390×844, 430×932, 844×390, 1440×1000). 페이지·모달 가로 넘침 없음. 320px는 데스크톱 Chromium의 좁은 CSS 뷰포트로 검사했다. 비용 부족·의료비·보너스·퇴직급여는 별도 저장 사례를 구성해 선택 결과를 엔진의 예상 상태와 깊은 비교했고 4개 모두 일치했다.
- [전액 옵트인 후 두 번째 행동](second-action-qa.json): IRP 대기자금 0원·남은 행동 1회·주문 그룹 1개. 매수/리밸런싱/디폴트옵션 비활성 사유 표시, X·포트폴리오 왕복 후 전체 게임 상태 일치.

시각 점검 중 발견한 모바일 카드의 세로 줄바꿈과 속보 띠의 가로 넘침을 수정했다. 초기 캡처 API가 실패해 뷰포트·배율을 조정한 후 다시 검사했다. 일부 직접 플레이 로그에 연결된 초기 스크린샷은 수정 전 상태를 포함하며, 아래 `verified` 사진을 최종 화면 기준으로 사용한다.
