# 디폴트옵션 직접 거래 · v1.5.0

## 화면과 사용자 흐름

「무엇을 할까요?」의 추가납입·매수·매도·바꾸기·리밸런싱·이번엔 그대로 카드는 기존 디자인을 유지한다. 마지막 카드 위에 같은 디자인의 「디폴트옵션 옵트인/아웃」 한 개를 추가한다. 자세한 탭·금액 입력·미리보기는 이 카드를 선택한 하위 화면에만 표시한다.

옵트인은 선택한 옵션의 매수 지시다. 사전지정과 독립적이며 주문 가능 IRP 대기자금, 구성품 금액, 결제 일정, 규제 위험비중과 기초 주식 노출을 보여 준다. 최소 10만원, 원 단위 금액을 허용하며 구성품이 10만원 미만이어도 지정한 비중대로 주문한다.

옵트아웃은 옵션 보유분 50% 또는 전부를 각 구성품에 같은 비율로 환매한다. 직접 매수한 같은 상품은 유지한다. 환매대금은 IRP 대기자금에 들어오며 사전지정 해제나 계좌 밖 중도인출이 아니다.

확정 시 운용 행동 한 번을 소비한다. 미리보기·탭 변경·포트폴리오 조회는 행동을 쓰지 않는다. X/Esc만 보드 복귀용 취소로 유지하며, 하위 화면의 뒤로 버튼은 운용 메뉴로 돌아간다. 포트폴리오 왕복·새로고침 후 이어하기는 탭·금액·환매 비율을 복원한다.

## 새 판의 규칙

- 지정은 향후 이용할 옵션을 저장하는 설정이다. 지정만으로 매수하지 않는다.
- 「이번엔 그대로」는 새 주문 없이 마감한다. 통지·대기 후 자동운용은 P1으로 남긴다.
- 한 종류 옵션만 보유한다. 추가 매수는 같은 옵션으로 가능하며 다른 옵션은 전량 환매 결제 후 선택한다. 진행 중인 옵션 주문이나 리밸런싱이 있으면 새 옵션 지시를 막는다.
- 예금은 신규 약정으로 즉시 편입하고 가입 건별 금리를 유지한다. 펀드는 접수 다음 턴 기준가 확정, 그다음 턴 결제다. 환매 가격 확정 전까지 시장 위험을 반영한다.
- 12턴 이후 일정은 추가 시장·급여 없는 최종 정산으로 처리한다. 마지막 구간의 화면도 가상의 13·14턴 대신 최종 정산으로 안내한다.
- 예금 조기 환매는 기존 게임 약정대로 발생 이자의 일부를 조정한다. 일반 중도인출의 허용 사유·재원별 과세는 기존 공통 처리 규칙을 따른다.

## 포트폴리오와 회계

실제 승인 상품을 복제하지 않는 교육용 포트폴리오 버전 `e1`이다. 규제 예외도 아래 가상 승인유형 묶음에 한정해 모사하며 직접 매수한 일반 상품에는 전파하지 않는다. 주식 노출은 규제 비중과 별도로 계산한다.

| 옵션 | 교육용 구성 | 가상 위험등급 |
|---|---|---|
| 원리금보장형 | 예금 100% | 6 |
| 저위험 | 예금 70% + TDF 30% | 5 |
| 중위험 | 예금 30% + 혼합형(BF 가정) 70% | 4 |
| 고위험 | 혼합형(BF 가정) 70% + TDF 30% | 3 |

초기 배분은 신규 매수 비중이며 가격 변동으로 실제 비중은 달라진다. 이름·등급·구성은 가상 사례이며 실존 상품의 원금·수익·승인 상태를 뜻하지 않는다. 기존 카탈로그는 C/D 판 재현용으로 보존한다.

상품별 합계 아래 `Holding.positions`로 직접 운용분과 옵션 운용분의 평가액·원금·수량·예금 약정을 나눈다. 옵션은 mandate/option/version 출처를 가진다. 일반 매도·교체·리밸런싱은 직접 운용분에만 적용하고, 옵션 환매는 해당 출처 구성품 전체를 비례 처리한다. 혼합 옵션의 예금만 생활사건 대응에 임의 사용하지 않는다.

미결제 주문은 같은 출처를 유지한다. 화면의 옵션 합계에는 미결제 주문이 포함되며 상품별 잔고와 이중 합산하지 않는다. 거래 묶음과 명령 ID로 중복 확정을 막는다. 미리보기는 원본 상태를 변경하지 않고 전체 구성품의 성공 여부를 확인한 뒤 확정한다.

## 저장·복기·학습

새 UI 게임은 `rulesetVersion: 2026-09-10-e`, `defaultTrading.version: e1`, 저장 `c3`을 사용한다. 설정 저장 키와 기존 진행 저장 키를 유지한다. 기존 c1/c2 C/D 진행에는 출처를 추정해 붙이지 않고 원래 규칙으로 완료하게 한다.

D의 시장·미션·운용지수는 유지한다. 옵션 거래는 외부 입출금으로 계산하지 않는다. 턴 복기·3/6/9턴 분기·JSON에 옵션 잔고와 주문을 포함한다. 저장 복원 시 합계, 출처, 주문 연결, 중첩 분기와 복기 자료를 검증한다.

디폴트옵션 학습 카드의 지정·옵트인·옵트아웃 설명과 관련 행동을 수정했다. 사용자·운영자 매뉴얼의 현재 버전 안내를 새 규칙으로 생성하며 이전 규칙은 접힌 과거 설명으로 보존한다.
