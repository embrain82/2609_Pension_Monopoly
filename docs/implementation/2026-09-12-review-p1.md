## 호환과 계산 경계

- 금융 계산·세금·납입/위험 한도·점수 수식·시장 RNG·주문 단계·현재 디폴트옵션 직접 거래 규칙을 유지했습니다. 거래 엔진 수정 중 `fundTiming`은 마지막 구간 설명만 분기하며 거래의 가격·결제 턴을 바꾸지 않습니다.
- `learningFlow.version = settlement-v1`은 새 UI 판에만 생성합니다. 필드가 없는 c1/c2/c3 진행은 기존 퀴즈 순서를 유지하고 새 필드는 복원 때 검증합니다. 분기 저장에도 학습 상태를 보존합니다.
- `profileAssessment`로 진단·확인 여부를 구분합니다. 이력 없는 과거 저장은 실제 진단 결과로 추정하지 않습니다. 준비 중 선택은 초안이며 최종 시작 전 자산·기존 진행을 덮어쓰지 않습니다.
- 신규 자동 추천은 재진단한 성향에 따라 바뀝니다. 사용자가 직접 고른 적합한 옵션은 유지하며 성향 밖이면 알리고 조정합니다. 캐릭터는 외형, 사전지정은 선호 저장이며 매수와 다릅니다.
- 연금 수령 업적은 이름만 중립적으로 바꾸고 기존 `annuity-choice` ID·조건은 보존합니다.
- X 취소, 운용 카드 메뉴, 맨 아래 포트폴리오, 시장 상세 펼침 상태, 턴 합계 납입 200만원을 유지했습니다.
